# To-Do List Web App

This project is a simple and responsive To-Do List web application built using HTML, CSS, and Vanilla JavaScript as part of a web development internship task.

## 📌 Objective
The goal of this project is to create a dynamic task management interface where users can add, complete, and delete tasks in real time without reloading the page.

## 🚀 Features
- Add new tasks using input field
- Display tasks dynamically on the screen
- Mark tasks as completed (toggle functionality)
- Delete tasks individually
- Prevent adding empty tasks
- Instant UI updates without page refresh

## 🧠 Concepts Used
- DOM Manipulation
- Event Listeners
- Dynamic Element Creation
- Class Toggling
- Basic JavaScript Logic

## 🛠️ Technologies Used
- HTML5 (Structure)
- CSS3 (Styling and Layout)
- JavaScript (Functionality and Logic)

## 📂 Project Structure
- index.html → Main structure of the app
- style.css → Styling and layout design
- script.js → JavaScript logic and interactivity

## 💡 Learning Outcome
Through this project, I learned how to handle user interactions, update the UI dynamically, and work with JavaScript DOM methods and event handling.
